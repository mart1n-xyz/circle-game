# Typefaces

Self-hosted Latin subsets of DM Sans (variable, weight 400–700) and DM Serif Display (regular), distributed under the SIL Open Font License. License text is included alongside each font.

- [DM Sans source](https://github.com/google/fonts/tree/main/ofl/dmsans)
- [DM Serif Display source](https://github.com/google/fonts/tree/main/ofl/dmserifdisplay)

The application makes no requests to a remote font service. Project illustrations in `app/src/Art.tsx` are original inline vector scenes. Interface icons come from Lucide, under its ISC license.
